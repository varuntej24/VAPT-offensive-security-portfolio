## Methodology

My general testing workflow:

1. Define scope and obtain authorization.
2. Perform reconnaissance and enumeration.
3. Identify potential vulnerabilities.
4. Validate findings safely within the approved scope.
5. Assess impact and document evidence.
6. Recommend remediation.
7. Retest fixes when authorized.
